# Changelog

## 0.1.0

First Marketplace release.

- Node Graph (rqt_graph): Nodes / Active / All topics views, filters, namespace grouping, per-topic rates, duplicate node name warnings, PNG export.
- Topic Monitor (rqt_topic): rate, period statistics, bandwidth, message size, header-stamp delay, publishers and subscribers with QoS, live message tree.
- Image View (rqt_image_view): raw, compressed and depth images, occupancy grids, colormaps, zoom, pixel readout.
- 3D / Point Cloud: PointCloud2 and LaserScan with field colouring, decimation and decay.
- Plot (rqt_plot), Service Caller, Publisher, Parameters (rqt_reconfigure), Console (rqt_console), TF Tree (rqt_tf_tree) with frame lookup.
- URDF Viewer: `/robot_description`, `robot_state_publisher` parameter or `.urdf` / `.xacro` files with live reload; JointState topics or local sliders; STL / DAE / OBJ / GLB meshes.
- Graph Explorer and Tools views, status bar with distribution, domain and graph size.
