# Third-Party Notices

The webview bundles in `dist/webview/` include the following open-source components. All of them are distributed under the MIT License; their license texts follow.

| Component | Version | Used for |
|---|---|---|
| [three](https://threejs.org) | 0.170.0 | 3D rendering (3D / Point Cloud view, URDF Viewer) |
| [cytoscape](https://js.cytoscape.org) | 3.30.4 | graph rendering (Node Graph, TF Tree) |
| [cytoscape-dagre](https://github.com/cytoscape/cytoscape.js-dagre) | 2.5.0 | layered graph layout |
| [dagre](https://github.com/dagrejs/dagre) | 0.8.5 | layered graph layout (used by cytoscape-dagre) |
